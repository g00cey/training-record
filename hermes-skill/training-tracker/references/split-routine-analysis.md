# スプリットルーティン分析ガイド

## 筋肥大に最適な Train 頻度

筋肥大研究（Schoenfeld et al.）に基づく推奨:

| 頻度 | 効果 |
|------|------|
| 週1回 | 最低限（維持は可能） |
| 週2〜3回 | 筋肥大に最適 |
| 週4回以上 | 追加効果は頭打ち、回復が課題 |

### ボリューム計算

セッション別ボリューム = Σ（重量 × 回数 × セット数）

週間ボリューム = セッションボリューム × 週間頻度

**例**:
- FW ヒップストラスト: 38kg × 40r × 1セット = 1,520/セッション
- 週間: 1,520 × 3.5 = 5,320

## 筋肥大のためのボリューム増加戦略

1. **セット数増** → 最も効果的（筋肥大の剂量-反応が明確）
2. **レップ数増** → 低レップ域（10〜15r）の種目で有効
3. **重量増** → 高レップ域（20r以上）の種目では効率が悪い

### 種目別アプローチ

| 種目 | 現在のレップ数 | 推奨アプローチ |
|------|---------------|---------------|
| 懸垂 | 10r | レップ増（15〜20r）or おもり追加 |
| ダンベルデッドリフト | 15r | レップ増（20r）or 重量増 |
| ショルダープレス | 30r | 重量増（レップ増は効率悪い） |

| バックエクステンション | 60r | もう限界、維持 |

## 故障予防のための頻度チェック

```
# 2週間の実施回数を確認
summary --days 14

- 自重: 12回以上/2週 → 良好（毎日維持）
- FW: 5〜7回/2週 → 良好（1日おき維持）
- 自重 + FW 合計: 17回以上/2週 → 非常に良好
```
